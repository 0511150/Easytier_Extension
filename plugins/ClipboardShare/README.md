# 剪贴板共享插件 (`clipboard-share`)

在 EasyTier 虚拟局域网内的多台电脑之间共享剪贴板：复制后立即同步到你选择的设备，并在本机保留一份按时间分色显示的剪贴板历史。内容直接走虚拟网卡点对点传输，不经过任何服务器。

## 安装方式

在 `EasyTier with Extension` 客户端左侧 **插件中心 → 官方商店** 中安装（需主程序版本 `>= 1.4.0`）。**共享双方都需要安装并启用本插件。**

## 使用方法

1. 打开左侧菜单 **剪贴板共享 - 剪贴板**，“共享设备”列表会列出各组网内同样运行本插件的设备。
2. 点击设备行的 **共享**，对方页面会弹出 **共享请求**，对方点 **同意** 后双方完成配对（60 秒内未处理视为拒绝）。**只有第一次需要对方同意**，之后重启、换网络或掉线重连都会自动连接。
3. 配对是双向的：之后任何一方复制文字或图片，都会立即发送给另一方并写入对方的剪贴板，对方直接粘贴即可。
4. 设备行操作：
   - **暂停**：不再向该设备发送（仍接收对方发来的内容）；暂停期间复制的内容恢复后也不会补发。暂停后点 **共享** 即恢复。
   - **取消共享**：删除配对并通知对方，再次共享需要对方重新同意。
5. 状态列说明：`双向同步` 表示双方都在互相发送；`发送中 · 对方未发送` 表示对方暂停了向你发送；`离线 · 上线后自动合并` 表示对方暂时不在线。

## 剪贴板历史

- 本机复制和收到的内容都会进入历史，最新的在最上面。点 **复制** 把该条重新放回剪贴板（同时同步给已共享的设备），点 **删除** 只删除本机这一条。
- 相同内容只保留一条（按内容识别），再次复制时移到最前。
- **左侧色条按复制后经过的时间着色**：绿色 1 分钟内、蓝色 10 分钟内、紫色 1 小时内、橙色 24 小时内、灰色更早，列表上方有图例。
- **不限条数**，按 **自动清除** 设置在复制后指定时间清除（10 分钟 / 30 分钟 / 1 小时 / 6 小时 / 24 小时 / 从不，默认 1 小时）。
- 历史**只保存在内存中，不写入磁盘**，退出插件或主程序即清空。

## 掉线重连与合并

- 与已共享设备断开期间，双方各自复制的内容都会留在自己的历史里。
- 重新连上后自动合并：双方互相补发对方缺少的、自己复制的记录，合并后的历史按复制时间排序（会换算两台设备的时钟差），补发来的记录带 **重连合并** 标签。
- 合并后，如果对方补发的最新一条比你剪贴板里的当前内容更新，会自动写入你的剪贴板，两边最终保持一致；更早的内容只进入历史，不会覆盖你后来复制的内容。
- 只补发**自己复制的**内容，不会把从 A 收到的内容转发给 C；配对之前、暂停期间或关闭同步时复制的内容也不会补发。

## 同步设置

| 设置 | 说明 |
| --- | --- |
| 同步剪贴板 | 总开关。关闭后不发送也不接收，期间复制的内容只记录在本机，重新开启后也不会补发 |
| 自动清除 | 历史记录在复制多久后清除 |
| 同步图片 | 关闭后图片只记录在本机，也不接收其他设备的图片。单张图片不超过 20 MB |
| 写入剪贴板 | 收到内容后直接替换本机剪贴板；关闭后只进入历史，需要时点“复制” |

## 支持的内容

- 文字（Unicode，最大 20 MB）与图片（截图、从网页或图片软件复制的图片，统一以 PNG 传输；来源程序提供 PNG 格式时保留透明度）。
- 暂不支持复制的文件。
- 密码管理器等程序标记为“不要监视 / 不上传到云剪贴板”的内容（如 KeePass、1Password 复制的密码）**不会记录也不会同步**。

## 网络端口与安全

- `TCP 39710`：接收服务，**只监听本机各虚拟网络的虚拟 IP**，局域网和公网无法访问。
- 首次共享时由发起方生成随机密钥，经对方同意后双方保存；之后每次连接都用 HMAC 质询应答验证，密钥本身不再在网络上传输。未配对或已取消共享的设备发来的内容一律拒绝。
- 首次开放端口时 Windows 防火墙可能弹出提示，请允许 `ClipboardShare.exe` 通信，否则其他设备无法向你同步（你向别人同步不受影响）。

## 数据目录

`%AppData%\Easytier_With_Extension\plugins_data\clipboard-share\`

- `identity.json`：本机设备 ID（用于识别配对关系）
- `pairs.json`：已共享的设备与密钥
- `settings.json`：同步设置

剪贴板历史不保存到磁盘。
