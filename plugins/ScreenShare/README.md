# 屏幕共享插件 (`screen-share`)

基于 EasyTier 虚拟局域网的低延迟多人屏幕共享插件，支持程序窗口捕获、多显示器桌面捕获、系统音频同步与可选远程键鼠控制。

## 安装方式

本插件采用与主程序分离的分发方式，在 `EasyTier with Extension` 客户端左侧 **插件中心** 中即可直接下载安装与更新（需主程序版本 `>= 1.1.0`）。

## 主要功能

1. **直观分栏选源（程序 / 屏幕）**
   - **程序**：枚举当前桌面可捕获的运行窗口并生成 `288×162` 实时缩略图卡片，支持一键 `↻ 刷新`；基于 WGC (`Windows.Graphics.Capture`) 捕获指定窗口，目标窗口关闭时自动停止共享。
   - **屏幕**：支持单显示器与多显示器选择，并展示各屏幕缩略图预览。
2. **仅屏幕模式可选输出分辨率**
   - 选择 **程序** 时自动跟随目标窗口比例与尺寸，不展示多余分辨率选项。
   - 选择 **屏幕** 时支持 **原始分辨率** 及分组常见 `[16:9]`（`3840x2160`、`2560x1440`、`1920x1080`、`1600x900`、`1366x768`、`1280x720`）与 `[16:10]`（`3840x2400`、`3200x2000`、`2880x1800`、`2560x1600`、`2240x1400`、`1920x1200`、`1680x1050`、`1440x900`、`1280x800`）预设，按源比例等比缩放并填充黑边，不拉伸不变形。
3. **画质与帧率预设**
   - **画质（码率）**：提供 `2 Mbps`、`4 Mbps`（默认）、`6 Mbps` 三档分段按钮（同码率下帧率越低单帧画面越清晰）。
   - **帧率**：提供 `15 FPS`、`30 FPS`（默认）、`60 FPS` 三档分段按钮。
4. **音频、远控与全局网络生效**
   - 默认开启 **共享声音**（通过 `WASAPI Loopback` 捕获系统音频并采用 `Opus` 编码同步传输）。
   - 默认关闭 **允许远控**（需共享端显式开启后，观看端方可申请单人互斥远程键鼠控制；控制中可按 `Ctrl + Alt + Esc` 随时释放控制权）。
   - 开启共享后自动生效到当前所有已连接的 EasyTier 虚拟网络，同网络内运行本插件的节点可在上方列表直接点击 **观看** 或 **远控**，在主程序内嵌 D3D11 视图中实时观看。
5. **H.265 优先、硬件编解码**
   - 共享端编码器按 **H.265 硬件 → H.264 硬件 → H.264 软件** 的顺序选择（硬件编码即显卡的 NVENC / Quick Sync / AMF）。
   - 只有当前 **全部观众** 都能硬解 H.265 时才发 H.265；有观众不支持（含旧版本插件）就自动改发 H.264，观众进出时实时切换。
   - 观看端用 D3D11（DXVA）硬件解码，画面直接留在显存，由显卡完成 NV12 → RGB 转换；显卡不支持时自动改用软件解码（仅 H.264）。
   - 编码器连续出错或长时间无输出时自动换下一个；共享状态与观看状态里分别显示当前的编码 / 解码方式。

## 网络端口

- `TCP 39600`：控制信令（握手、参数同步、静音、远控申请与键鼠事件）
- `UDP 39601`：H.264 / H.265 视频分片与 Opus 音频流传输
