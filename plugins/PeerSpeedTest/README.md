# 对端测速插件 (`peer-speedtest`)

测试 EasyTier 虚拟局域网内到其他节点的真实延迟、抖动与上下行带宽。测速流量直接走虚拟网卡点对点传输，结果反映的是当前链路（P2P 直连或中转）下应用实际能拿到的速度。

## 安装方式

在 `EasyTier with Extension` 客户端左侧 **插件中心 → 官方商店** 中安装（需主程序版本 `>= 1.2.0`）。**测速双方都需要安装并启用本插件。**

## 使用方法

1. 打开左侧菜单 **对端测速 - 测速**，上方列表会列出各组网内同样运行本插件的在线节点，以及它们的链路类型（P2P / 中转）和 EasyTier 测得的延迟。
2. 点击节点行的 **测速**，等待对方同意（对方 30 秒内未处理视为拒绝）。
3. 对方同意后依次进行：
   - **延迟测试**：20 次 TCP 往返，给出平均延迟与抖动；
   - **上传测试**：本机向对方持续发送 **15 秒**；
   - **下载测试**：对方向本机持续发送 **15 秒**。
4. 测速过程中 **速率曲线** 每 100 毫秒采样一次实时刷新，横轴为本方向开始后的秒数（0 ~ 15 秒），鼠标悬停可查看任意时刻的速率。可随时点击 **停止测速** 中止。
5. 每个方向的结果取 **最后 5 秒的平均速率**（避开 TCP 慢启动阶段），在曲线上以同色虚线标出，并显示在底部统计、节点行的“最近结果”和 **测速记录**（最多 50 条）中。

> 并发线程（1 / 4 / 8）：多线程更容易跑满带宽，单线程更接近单个应用（如单个文件传输）的实际速度。

## 被测速时

- 有人对你发起测速时，主程序会自动切换到本插件页面，顶部出现 **测速请求**，显示对方名称与虚拟 IP，可点击 **同意** 或 **拒绝**；30 秒内未处理自动拒绝。
- 测速进行中可点击 **中止被测速** 随时结束，所有测速连接会立即断开。
- 自己正在测速或已有待确认请求时，新的请求会被自动拒绝；同一时间只服务一个发起方。

## 网络端口与安全

- `TCP 39700`：测速服务，**只监听本机各虚拟网络的虚拟 IP**，局域网和公网无法访问。
- 每次测速都必须经被测方同意；同意后发放一次性会话凭据，只对发起方的虚拟 IP 有效，测速结束或被中止即失效。
- 首次开放端口时 Windows 防火墙可能弹出提示，请允许 `PeerSpeedTest.exe` 通信，否则其他节点无法对你测速（你主动测速别人不受影响）。

## 数据目录

`%AppData%\Easytier_With_Extension\plugins_data\peer-speedtest\`

- `settings.json`：并发线程设置
- `history.json`：测速记录
