# 对端测速插件 (`peer-speedtest`)

测试 EasyTier 虚拟局域网内到其他节点的真实延迟、抖动与上下行带宽。测速流量直接走虚拟网卡点对点传输，结果反映的是当前链路（P2P 直连或中转）下应用实际能拿到的速度。

## 安装方式

在 `EasyTier with Extension` 客户端左侧 **插件中心 → 官方商店** 中安装（需主程序版本 `>= 1.1.0`）。**测速双方都需要安装并启用本插件。**

## 使用方法

1. 打开左侧菜单 **对端测速 - 测速**，上方列表会列出各组网内同样运行本插件的在线节点，以及它们的链路类型（P2P / 中转）和 EasyTier 测得的延迟。
2. 选择 **测试项目**（下载 / 上传 / 双向）、**单项时长**（5 / 10 / 20 秒）与 **并发线程**（1 / 4 / 8）。
3. 点击节点行的 **测速**。插件依次进行：
   - **延迟测试**：20 次 TCP 往返，给出平均延迟与抖动；
   - **下载测试**：对方向本机发送数据；
   - **上传测试**：本机向对方发送数据，以对方实际收到的数据量为准。
4. 测速过程中可查看 **实时速率**，或点击 **停止测速** 随时中止。结果显示在节点行的“最近结果”中，并保存在 **测速记录**（最多 50 条）。

> 说明：每项测试开头最多 1 秒的数据不计入结果，以避开 TCP 慢启动。多线程更容易跑满带宽，单线程更接近单个应用（如单个文件传输）的实际速度。

## 被测速设置

- **允许他人对我测速**（默认开启）：关闭后本机不再监听测速端口，其他节点的列表中会显示“对方未开放”。
- 单次测试时长被限制在 30 秒以内，同时最多接受 32 个测速连接。

## 网络端口与安全

- `TCP 39700`：测速服务，**只监听本机各虚拟网络的虚拟 IP**，局域网和公网无法访问。
- 首次开放端口时 Windows 防火墙可能弹出提示，请允许 `PeerSpeedTest.exe` 通信，否则其他节点无法对你测速（你主动测速别人不受影响）。

## 数据目录

`%AppData%\Easytier_With_Extension\plugins_data\peer-speedtest\`

- `settings.json`：测速设置
- `history.json`：测速记录
