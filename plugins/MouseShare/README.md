# 共享鼠标插件 (`mouse-share`)

用一套键盘鼠标控制 EasyTier 虚拟局域网内的多台电脑：把各台设备的显示器排好位置，光标移到与另一台设备相接的屏幕边缘，就会切换过去控制那台电脑，移回来即回到本机。键鼠数据直接走虚拟网卡点对点传输，不经过任何服务器。

## 安装方式

在 `EasyTier with Extension` 客户端左侧 **插件中心 → 官方商店** 中安装（需主程序版本 `>= 1.4.0`）。**所有要共享的电脑都需要安装并启用本插件。**

## 使用方法

1. 打开左侧菜单 **共享鼠标 - 屏幕排列**，“设备”表会列出各组网内同样运行本插件的电脑。
2. 点击设备行的 **添加**，对方页面会弹出 **添加请求**，对方点 **同意** 后双方完成配对（30 秒内未处理视为拒绝）。只有第一次需要对方同意，之后重启、掉线都会自动重连。
3. 新添加的设备会放在本机右侧。在 **屏幕排列** 中拖动矩形调整位置：同一台电脑的显示器整体移动，靠近其他屏幕的边缘时会轻微吸附；松手时如果没有与任何屏幕相接，会自动贴到最近的边上。
4. 光标碰到与另一台设备相接的那段边缘时切换过去。只有相接的部分可以穿越，例如左右两块屏幕高度不同，只有上下重叠的那一段能过去。

## 显示器大小

点击排列中的显示器即可在 **显示器** 中设置它在排列中的大小，跨屏时的落点与移动速度都按这个大小换算：

| 大小 | 说明 |
| --- | --- |
| 跟随系统 | 默认。按该显示器的 Windows 缩放换算（如 4K 150% 等同 2560 × 1440） |
| 100% ~ 300% | 指定缩放，不必与 Windows 设置一致 |
| 按屏幕尺寸 | 输入对角线英寸数，按实际物理尺寸排列；不同尺寸、分辨率的屏幕之间移动时，光标在物理上走过相同距离 |

点 **识别** 会在每块屏幕中央短暂显示它的编号，方便对应排列中的矩形。

## 切换规则

- 控制其他电脑时，本机光标会隐藏并停在原处，本机键盘输入也发送到对方；移回本机时光标从相接的位置出现。
- 按住鼠标键时不会切换屏幕（拖动无法跨电脑）。切换前本机仍按着的键会先松开，离开对方时对方仍按着的键也会松开，避免卡键。
- 正被控制的电脑上直接动一下自己的鼠标或点击，就会收回控制权。
- 连接断开时立即回到本机。点 **暂停共享** 后本机既不控制也不被控制。
- 无法跨入锁屏、UAC 确认等安全桌面；Ctrl+Alt+Del 只对本机有效。

## 安全与网络

- 只有双方同意配对后才能互相控制。每次连接都用配对时生成的密钥双向验证，未配对的设备只能发起添加请求。
- 键鼠数据经 TCP `39720` 端口传输，只监听本机的虚拟网卡 IP。
- 在设备表中点 **移除** 会删除配对并通知对方，再次使用需要重新添加。

## 数据目录

`%AppData%\Easytier_With_Extension\plugins_data\mouse-share\`：`settings.json`（本机设备 ID 与开关）、`peers.json`（已配对设备与密钥）、`layout.json`（排列与各显示器的大小设置）。
